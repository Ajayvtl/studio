# **App Name**: DataLens

## Core Features:

- Add User Form: A user-friendly interface for adding new users with fields for name, middle name, title, email, and mobile number.
- Add Country Form: Form to add pre-filled countries with time zones and ISO codes.
- Add Exchange Form: Form to add major stock exchanges country-wise, including social media links, time zones, holiday schedules and weblinks.
- Sentiment Analysis: AI Tool that assists in determining the sentiment of news articles and social media posts related to specific stocks, providing a general indicator of market sentiment. The AI tool will use reasoning to decide when to incorporate articles in it's output.
- UI Settings Panel: A dedicated settings panel to configure data fetching frequency and custom scripts for data integration.
- Add Package Functionality: Functionality to add packages for clients.
- Client Management: Client management with email verification, registration, blocking functionality, activity logging, and IP logging.
- Add Stocks: Add stocks as per exchanges with a separate table for historical records.
- Fetch Live Data: APIs for fetching technical and live data from websites like Yahoo Finance.
- MIF Data Upload: Functionality to upload MIF data.
- Geographical Data Upload: Functionality to upload geographical data.
- Custom Data Management: Custom data upload and management with live search.
- Data Science Integration: Integration of free data science libraries for data analysis.

## Style Guidelines:

- Primary color: Deep blue (#1A237E) for a professional and trustworthy feel.
- Secondary color: Light gray (#ECEFF1) for backgrounds and subtle contrasts.
- Accent: Teal (#26A69A) for interactive elements and data visualization highlights.
- Clean, grid-based layout for organized data presentation.
- Use minimalist, consistent icons for navigation and data representation.
- Subtle transitions and animations for interactive elements, such as expanding data rows or loading indicators.
